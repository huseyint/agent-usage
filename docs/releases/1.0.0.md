AI Coding Usage 1.0.0 brings Claude Code and Codex usage into one local desktop dashboard.

- Browse sessions, search and filter conversations, and add local titles, tags and favorites.
- See token usage, estimated costs, usage trends, and project and model breakdowns.
- Set monthly allowances, export CSV or JSON reports, and check recent sessions from the menu bar or system tray.
- Use light or dark themes and custom source folders. Your logs stay on your machine, with no account, API keys, telemetry or uploads.

Available for Apple Silicon Macs, Windows x64 and Linux x64. Costs are API-equivalent estimates, not subscription charges or provider quota usage.
